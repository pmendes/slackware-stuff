# slackware packages

Here I have slackware packages ready to install with installpkg or upgradepkg. Note that these are 
all for Slackware64.

* cmake-3.17.3 for Slackware 14.2 (compiled using Pat's slackbuild in slackware-current) 
* crafty-25.2 the legendary chess engine, compiled for Slackware 15.0
* sloppy-0.2.3 a chess engine, compiled for Slackware 15.0
